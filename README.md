# Cleanora - Мобильное приложение для клининговых услуг

Cleanora - это полноценная платформа для предоставления клининговых услуг, состоящая из мобильного приложения для клиентов и административной панели управления для бизнеса.

## Структура проекта

Проект состоит из двух отдельных модулей:

1. **CleonoraRest** - RESTful API для мобильного приложения
   - Документация API: [http://slj.demodev.cc:7939/cleonora/v1/swagger-ui/index.html](http://slj.demodev.cc:7939/cleonora/v1/swagger-ui/index.html)

2. **CleonoraAdmin** - Административная панель для управления сервисом
   - Административная панель: [http://slj.demodev.cc:7940/cleonora/admin/](http://slj.demodev.cc:7940/cleonora/admin/)

## Архитектура

Проект построен на микросервисной архитектуре с двумя основными компонентами:

1. **REST API (CleonoraRest)**: Обслуживает запросы мобильного приложения, обеспечивая все необходимые эндпоинты для функционирования клиентской части.

2. **Админ-панель (CleonoraAdmin)**: Предоставляет интерфейс для администраторов и менеджеров системы с возможностью управления всеми аспектами бизнеса.

Оба компонента независимо развертываются в Docker-контейнерах и взаимодействуют с общей базой данных PostgreSQL.

## Функциональность

### Мобильное приложение
- Регистрация и авторизация пользователей
- Просмотр доступных услуг
- Заказ услуг клининга
- Выбор адреса и времени уборки
- Оплата услуг
- Отслеживание статуса заказа
- История заказов

### Административная панель
- Управление пользователями
- Управление услугами и тарифами
- Просмотр и обработка заказов
- Аналитика и отчеты
- Управление персоналом
- Настройки системы

## Развертывание

Проект настроен для автоматического развертывания с использованием CI/CD (GitHub Actions):

1. При пуше в ветку main/master:
   - Собираются Docker-образы для обоих компонентов
   - Образы публикуются в Docker Hub
   - Производится автоматическое развертывание на сервере

2. Конфигурация развертывания:
   - CleonoraRest работает на порту 7939
   - CleonoraAdmin работает на порту 7940
   - PostgreSQL работает на порту 5440
